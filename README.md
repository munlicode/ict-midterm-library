## What was implemented

- Lo-fi version of a Uni library assistant.
- 4 mock pages: home, search, book details, about.
- 3 Language support. New languages can be added if needed. To add a new language, follow instructions in `src/i18n/index.ts`.
- Convienent filtering.
- Fuse Search that is more accurate than string comparison search.
- Login using Microsoft Entra ID instead of username and password login.

## Note

This version is prototyped and focused on speed. Code is not be efficient and production-ready.
There are a lot of hard-coded values, but protype does its job and makes library portal more user-friendly and secure.
